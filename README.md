# FPS感度ツール スマホ版 UI最適化 v23

スマホ版向けの非公式参考感度ツールです。

## 主な仕様
- 2本指基準
- かんたん設定：武器選択なし。ジャイロあり / なしだけで全武器共通のおすすめ感度を表示
- 詳細設定：武器別に基準スコープを1つ選び、表示されている数字を−/＋または直接入力で微調整
- DMR：4倍メイン / 6倍メイン / 8倍メインから選択
- SR：8倍メイン / 6倍メイン / 4倍メインから選択
- AR / SMG / SG / LMG：実戦で使う近距離〜中距離スコープを基準に選択
- SG：肩越しTPP / TPPノンスコ / レッドドットから選択。2倍以上は非表示
- 肩越しTPP / FPP対応
- ジャイロON/OFF対応
- プレイスタイル補正はカメラ・ADS・ジャイロカメラ・ジャイロADSすべてに反映
- PWA対応

## v23 SG/UI整理
- SGカテゴリを追加
- SGは5〜50mの近距離レンジ、肩越しTPP / TPPノンスコ / レッドドット基準に対応
- 基準感度入力に−/＋ボタンを維持
- 1から入力し直さず、表示値から微調整する流れを強化
- かんたん/詳細の現在モード説明を追加
- 完全感度一覧を必要時だけ開く構成に整理
- 未使用定数・旧版コメントなどの不要コードを整理
- プレイスタイル補正がカメラ/ADS/ジャイロカメラ/ジャイロADSすべてに反映されることを再確認
- 白背景アイコンなしの黒×ゴールド系アイコンを維持

## 注意
本ツールは、実戦向けの参考感度を算出する非公式ツールです。最終的な感度は、端末・指配置・プレイスタイル・ジャイロの使い方・個人の感覚によって変わります。トレーニング場や実戦で確認しながら、自分に合わせて微調整してください。
